是，当前预先指定的主比较确实没赢；但“主比较没赢”“信号本身没有价值”“研究失败了”，是三件不同的事。
**完全可以往有分量的反直觉研究走——这本来也符合我们最初的 scope：检验现有经验价值判断是否可靠，而不是必须发明一个获胜的方法。**不过，不能现在就把“一个 Beta 预测器没打赢常数”包装成“可学习性不能预测迁移”。
我这次重新核对了标签聚合、评测与预测代码，并用公开的逐来源、逐训练重复数值复算。**没有发现直接把主结果算反的错误，但发现了两个需要认真解释的问题：来源收益排序的重复稳定性有限，以及 Coverage 与特定工具身份完全重合。**这比单纯说“接受负结果”更重要。
一、先说清楚：到底哪个结果不好？
当前结果实际上是：
比较	局部奖励机会预测	训练后迁移收益预测
任务级 Beta vs. 组合级 Beta	任务级更好	任务级也更好
任务级 Beta vs. 不使用信号的均值基线	不是同一项比较	任务级更差


局部 Brier 是任务级 0.2354、组合级 0.3412；迁移 MSE 是任务级 0.0003090、组合级 0.0008972，而均值基线为 0.0002494。
**因此，当前并没有出现“任务级在局部赢了组合级，到了迁移却输给组合级”的排名反转。**它在这两个比较上都优于组合级，只是仍不如直接预测平均迁移收益。
这决定了我们现在能说：
改进局部机会估计，并不足以保证该信号能提供优于常数基线的迁移价值预测。

但不能偷换成：
“局部预测越准确，迁移预测反而越差。”

另外，**RL 干预本身并非完全没有收益。**16 个来源的平均 \(G\) 都为正，整体平均约＋5.24 个百分点；Uniform 平均约＋8.33 个百分点。失败的是主候选的预测检验，不是所有训练都没有学到东西。
二、有没有可能是代码或实验哪里出了问题？
有这种可能，不能因为审计文件写着 passed 就排除。但目前我查到的证据，并不支持“只是算错了”这个解释。
标签代码确实按对应评测 seed 扣共同起点，再在训练重复内、重复间依次平均；\(V\) 使用对应 Uniform 重复。评测入口加载各分支 adapter、核对政策指纹，并在推理模式下验证权重未变。没有看到“所有终点其实都评了同一个 base”或“扣错 baseline”的直接问题。
我也重新计算了 ridge 与四个留出来源的误差，结果与报告一致。当前标准化后的 12 个拟合来源，ridge 的惩罚相当于将普通一元最小二乘斜率乘以 \(12/13\)，不是一个特别强的正则把原本很强的关系压没了。按现有拟合数据复算，任务级信号与来源平均 \(G\) 的 Pearson 相关也只有约 0.078。这是对已有数据的诊断，不是新增确认性检验。
**所以，暂时没有找到一个明确计算错误，修正后主结果就会翻转。**但我没有独立重跑 GPU 训练、逐条重新执行环境判题，不能据此保证整个训练与环境实现毫无问题。
更值得检查的，是下面这些会改变科学解释、却不一定表现为程序报错的问题。
三、现在真正值得追查的四个解释
1. 要预测的“来源价值排序”，自身有多稳定？
我把 16 个来源在三个训练重复中的 \(G\) 分别取出来——每个 \(G\) 已经平均了两个评测 seed——计算了来源排序之间的 Spearman 相关：
训练重复之间	来源收益排序相关
r0 与 r1	约 0.33
r0 与 r2	约 0.07
r1 与 r2	约 0.69


这是我依据完整报告中的逐重复数值做的事后描述性复算，不是总体显著性检验。r0、r1、r2 是随机重复，不是连续训练阶段。
这个结果说明：**我们目前还不能默认“存在一张非常稳定的来源价值排行榜，只是 Beta 没发现”。**不同训练重复之间，排序一致程度差异很大。
这会产生两种完全不同的解释：
**解释 A：**来源确实有可预测的价值差异，但当前信号没捕捉到。
**解释 B：**当前预算和测量精度下，来源收益本身波动很大，任何弱信号都难以预测。

两者都可能参与，不能用一次预测失败直接选 A，也不能因为有波动就认定全部是 B。少量训练运行的 RL 评测中，点估计与可靠的不确定性分析可能给出不同判断，这也是已有评测研究明确强调的问题。arXiv
**这里首先应利用已有逐任务、逐重复数据做配对分析，不是立刻再加十几个 seed。**共享 baseline、共同目标题要一起处理；四个留出来源很少，得到的区间也只能对应明确限定的条件。不能把相关数据当独立样本，但也不等于完全不能做不确定性分析。
2. “任务级估计更好”，不代表真正的局部学习机会已经测准
每题只有四条 feature 轨迹。按当前 Beta(1,1) 先验，四次成功数不同，预测下一组出现成功／失败混合的概率只有三档：
四次中的成功数	预测混合概率
0 或 4	约 43.65%
1 或 3	约 68.25%
2	约 76.19%


这是按冻结定义直接计算的。**即使四次全失败，这个估计器仍预测约 43.65% 的混合机会。**局部验证中，它的平均预测也确实高于实际混合频率，仓库并没有证明它已经准确校准。
因此，还不能把现在的结果解释为：
“我们精确测到了可学习性，但可学习性不能预测迁移。”

更准确的是：
“这个有限采样的局部机会估计器，比组合聚合更好；但它本身仍有测量误差，且没有通过迁移预测的主检验。”

**这不是要求现在重采到完美。**但要在已有独立 validation 中检查：它主要改善的是整体高估，还是也确实改善了来源之间的区分？这两种改进对后续价值预测的意义不同。
3. 我这次发现的具体混杂：Coverage 实际等同于一个工具身份标签
我逐组核对后发现，在当前全部 16 个来源中：
\[
\mathrm{Coverage}(g)
=
0.5+
0.5\,\mathbf 1
\left\{
g\text{ 包含 TravelAPI 或 VehicleControlAPI}
\right\}.
\]
**这不是近似相关，而是在这 16 行数据里完全成立。**包含这两种工具之一的组，Coverage 都是 1；其他组都是 0.5。
这意味着，当前 Coverage 预测器的表现，无法区分：
是“覆盖历史”真的具有预测价值？

还是：
这两类工具相关的来源，在当前目标面板上恰好具有不同的平均收益？

**这是一个解释上的不可辨识问题，不是数据泄漏，也不让原来的预测误差失效。**但它阻止我们把“Coverage 的 MSE 最低”直接解释成覆盖机制获胜。
而且，完全共线时，再把“工具身份”和“Coverage”一起塞进回归也拆不开。需要下一学习状态或另一个预设条件中出现不同对应关系，才有机会区分。已经计划的晚阶段可能提供这种变化，但要实际检查，不能默认它一定解决。
所以这次不只是要防止“硬救 Beta”，也要防止Beta 输了以后，马上把 Coverage 换成新的主角。
4. 当前测的是短预算下的来源干预，不是所有意义上的“经验价值”
这批每个分支实际只有 4–11 次优化器更新，生成预算、实际访问任务及有效梯度组数也有差异。我们用的是训练前固定信号，预测多次在线更新后的收益。
因此，失败可能涉及：
初始信号随政策更新变旧；来源组均值没有反映实际抽到的任务；更新方向对目标任务不合适；或者这个训练时长下的收益关系本来就不同。
这些不是推翻当前实验的理由——预算受控的短程经验价值是合法的研究对象——但不能从这里外推“长期训练也一样”。
还要注意：当前并没有同一批检查点的新 ID 主对照。**如果想写“在本域学会了，但没有迁移”，就需要对应的本域能力收益证据；混合奖励或非零梯度不能代替“学会了”。**只写“该代理没有改善迁移收益预测”，则不必为了一个更响亮的标题额外铺开全部 ID 实验。
四、那么，能不能做你说的“反结论 paper”？
能，而且值得继续。但要反驳一个具体推断，而不是把负号变成卖点。
我认为比较有价值的命题是：
能够产生局部奖励比较信号的经验，并不自动具有高迁移价值；局部代理的有效性，必须在真实学习干预后验证。

它有一个很清楚的技术直觉。令 \(J_T(\theta)\) 是目标任务上的期望表现，某来源训练产生参数变化 \(\Delta\theta_s\)。在光滑、小更新近似下：
\[
\Delta J_T
\approx
\nabla_\theta J_T^\top \Delta\theta_s.
\]
局部成功率或奖励混合概率，最多描述某些学习机会；迁移收益还取决于更新方向是否与目标需求一致。
举一个纯数学反例，而不是对当前实验的解释：设目标成功率为 \(J_T(\theta)=\sigma(\theta)\)，两个来源的成功率分别为 \(\sigma(\theta)\) 和 \(\sigma(-\theta)\)。在 \(\theta=0\) 时，它们成功率都为 0.5，四次采样出现混合奖励的概率都为 0.875；但分别沿各自成功率梯度更新，一个提高目标成功率，另一个降低。
**相同的奖励统计，可以对应相反的迁移方向。**这说明仅靠这种统计不存在一般性的充分保证。但这只是基本诊断原理，不能把这个简单反例当成整篇论文的新理论贡献。真正的贡献应该是：这种缺口在实际 agent RL 中影响多大，哪些信号因此失效，什么时候可以跨 learner 使用。
同时，要公平对待已有工作。比如 DAPO 的 Dynamic Sampling 是在采样后过滤全对／全错组，以保持有效梯度样本；它并不是承诺“训练前估一个混合概率，就能准确预测任意目标的迁移收益”。当前 Beta 实验失败，不能说成否定了 DAPO。arXiv
你之前关注的 RLVR 那类工作，值得学的也是这种拆分：它区分了小 \(k\) 下的答对概率与大 \(k\) 下的覆盖范围；而 ProRL 又报告了长期训练下不同的结果，强调训练时长和设置的作用。有价值的争论在于什么条件下哪种推断成立，而不是哪个标题更反直觉。arXiv
五、现在离一篇强的反直觉研究，还缺哪一步？
目前已有的是一个完整、可解释的特定预测器负结果。要提升为更强的结论，需要确定它为什么失败，以及失败是否超出这一个配置。
我会区分三种最终故事：
如果主要是代理测量不准：
论文应讲“经验价值代理的测量方式存在问题”，而不是“真实可学习性与迁移无关”。
如果局部机会确实能可靠预测，收益也能可靠测量，但两者的关系仍弱或随 learner 改变：
这才更接近我们想要的、关于局部机会与迁移价值之间差距的结果。
如果来源收益在当前预算下主要被随机波动淹没：
应报告这个测量极限及其代价，不能把“测不出来”当作“没有关系”。除非进一步把这个测量问题本身做成系统、可复用的发现，否则仅凭一个很嘈杂的负结果，论文说服力有限。
所以，现阶段还不能保证它已经是一篇很强的反结论论文；但也绝不是“方法没赢，只能包装负结果”。我们已经有一个真实的问题，现在要把替代解释分开。
六、我的具体建议：继续，但补的是解释，不是把方法救赢
**第一，做一份有限的、仅用已有数据的诊断补充。**重点就是此次发现的收益排序稳定性、局部代理的校准与区分能力，以及 Coverage—工具身份共线。把这些写清楚，标为事后分析；不重新选主指标，不改原 Stage 0 结果，也不为此启动新一轮 GPU 矩阵。
**第二，继续既定晚阶段，同时保留所有竞争解释。**最新仓库已经记录固定 Uniform r0 晚阶段探测启动，原早期模型保持封存。这个方向不用停；H1 成功率也应按独立辅助分析处理。晚阶段要检查的是信号—收益关系是否变化，而不是要求它证明某个预期故事。
**第三，跨模型验证仍保留，但围绕明确命题设计。**8B、另一家族及代际代表性的职责不变。若最终主张是“这是现代 agent RL 的一个重要代理有效性问题”，就需要相应外部证据；不能只有一个 4B 邻近检查点，就换成广泛的标题。也不需要每个模型复制全部探索过程。
这里我也修正一下此前“不要再排查、直接往下走”可能带来的误解：**不应无限验收，不等于不准检查负结果的替代解释。**有明确问题、能改变判断、尽量复用已有数据的诊断，是科学分析；为了追正结果不断换配置，才是我们要避免的。
我的最终判断是：主比较没过是真的，目前没有发现能直接翻转它的计算错误；但仍存在测量、来源身份混杂和训练尺度等解释，尚不足以宣布普遍的“反结论”。
我会继续这个项目，并允许论文的核心是负结果或条件性结论。但要把它做成“为什么常用代理不能直接代表迁移价值、其有效边界在哪里”，而不是“我们的 Beta 没赢，所以可学习性没用”。
这次最该做的，不是救 Beta，也不是拥抱 Coverage，而是把“代理失效、测量不足、真实的迁移关系变化”这三件事分清楚。分清了，反直觉结论才有分量。
