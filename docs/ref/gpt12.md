所以，不能只说“方向没变，放心做”，也不能简单说“又降级成支线了”。**更准确的是：我们从一个广泛比较各种经验价值假说的计划，逐渐走向了一条以“可学习性信号如何转化为迁移收益”为中心的研究路线。**这条路线可以有深度，但需要承认它与最初设想的区别。
一、最初真正想弄清楚的是什么？
我重新读了最早冻结的 01_scope.md。当时的核心不是：
哪个任务更容易成功？哪个采样策略训练 reward 更高？

而是：
同样花一笔训练预算，什么样的经验能让 agent 在没练过的任务上变得更强？现有的那些“经验价值分数”，到底能不能提前预测这个收益？ 

你说的“那个结论”，准确地讲，是我们希望判定的这组关系：
\[
\boxed{
\text{当前任务表现／局部学习信号}
\quad\stackrel{?}{\longrightarrow}\quad
\text{训练后的可迁移能力}
}
\]
当时并没有规定实验一定要证明“局部信号没用”。几种结果都符合原问题：某个已有信号确实可靠；信号只预测当前任务收益、不预测迁移；或者同一批经验的价值随着 learner 阶段、规模发生变化。真正固定的是要研究这段关系，而不是预先固定一个反直觉结论。 
另外，最初还有一个比较明确的研究雄心：把 success、diversity、information、recovery、compatibility、learnability 等不同答案放在同一框架里比较，而不是再提出一个新分数后只证明它涨点。
二、现在具体走到哪了？确实发生了三种不同的变化
维度	最初设想	现在实际的重心
最终要解释的结果	训练后迁移能力的增益	后续协议仍以迁移增益为目标，这一点保留了
比较的价值假说	多种机制不同的信号	主要围绕任务级／组合级可学习性，另保留历史覆盖度
干预对象	较宽泛的经验属性、轨迹与数据选择	从不同任务来源组获取经验，再进行在线 RL
最近已经得到的新证据	希望建立信号与迁移收益的关系	目前证明了任务级信号更好地预测下一组是否出现成功／失败混合


这些区别来自原始 scope、当前 47 的分析协议和 48 的实际结果。
这里最应该诚实承认的是第二行：
现在并没有在全面比较七八种“经验价值观”。
任务级 Beta、组合级 Beta、历史 Frontier，虽然名字和估计方法不同，但大体还属于成功率／可学习性这一类信号。当前的历史覆盖计数，也不能直接代表最初设想的所有结构多样性。因此，将来若按现在的方案完成，也不适合宣称“我们统一检验了所有主流经验价值假说”。
**这是一项真实的收窄，不只是换了更精确的措辞。**但收窄比较范围，不必然意味着研究价值下降：它可能换来对一个关键关系更深的解释。现在还要看后面的证据能不能兑现。
三、最新的任务级探测，是合理的主线一环，还是低一级的支线？
两者都可能，取决于我们最终拿它解释什么。
我们此前的逻辑大致是：
有人说“适中难度值得学” → 用某个 Frontier 分数选经验 → 看训练后迁移收益。

实际过程中发现了一个问题：
这个 Frontier 分数，可能连它声称衡量的“同一道任务上的学习机会”都没有估准。

例如，一个组里一半题总成功、一半题总失败，组合平均成功率是 0.5，但对单道题采四次，未必能产生任何成功／失败差异。最新实验确实发现：在当前固定模型和面板下，保留任务级结构，比先合并组合奖励，更好地预测独立四条轨迹的混合奖励事件。
**这一步不是无关绕路。**否则，假如旧 Frontier 预测不了迁移，我们根本分不清：
是“可学习性本身不能预测迁移”？

还是：
“我们拿来代表可学习性的东西，本来就没测对”？

把这两个解释分开，对原问题是有用的。
**但是——局部测量改进，不是迁移价值结论的替代品。**最新这批没有 RL 更新，也没有新增迁移 \(G/V\)，而且任务级预测虽然误差更低，仍然整体高估混合奖励机会。它不能支持“我们已经准确知道什么经验值得训练”。
因此，我会这样定位：
作为整篇研究的一部分，它是有用的测量发现；如果整篇论文最后停在这里，它就确实变成了一个比最初更窄的局部奖励代理研究。

这不是贬低它，只是两篇论文回答的事情不同。
四、现在的 47，还能把它接回原来的核心问题吗？
能，而且接法已经比较明确。
47 准备做的是：从共同 learner 状态出发，分别在不同经验来源组上进行预算受控的 RL，测实际迁移收益；然后用采样前的信号预测这些收益，并在未参与拟合的来源组上检验，还单独考虑早期模型对后期的预测能否成立。
这一步若完成，研究就从：
哪些任务比较容易产生混合奖励？

回到了：
对这种局部学习机会的判断，究竟能不能帮助我们预测“训练进去以后，在别的任务上有什么用”？

这就是原 scope 的核心，而不只是附近的题。
不过，它回来的是原 scope 的一个有限版本：以可学习性为主要切入点，研究来源组价值及阶段依赖；不是最开始那个多种经验价值机制全面比较的完整版本。
有三种可能的结果，需要区分。
第一，任务级信号改善局部预测，也改善未见来源组的迁移收益预测。
那么我们得到的就不只是“一个概率估计器更准”，而是：**估计经验的局部学习机会时，粒度会影响对真正训练价值的判断。**这是原主线上的一步。
第二，局部预测改善了，但迁移预测没有相应改善，而且差异经过足够可靠的测量。
那么它可能支持我们最初关心的“局部学习机会与迁移价值之间存在距离”。但必须排除标签噪声、样本量和预测模型限制，不能看到一个 ridge 没赢就宣布“可学习性不等于迁移性”已经被证明。
第三，只完成了局部预测改善，后面的迁移收益一直没有得到可靠测量。
那么就应承认：**目前拿到的是支线成果，原来的核心问题还没有回答。**不能因为支线出了正结果，就重新把它命名为“经验价值已经被理解了”。
所以关键不是未来一定得出哪种正负结果，而是最终解释的变量，是否真的回到了训练后的迁移收益。
五、我觉得真正需要警惕的，不是“范围小了”，而是终点被悄悄替换
你这次问得很重要，因为我们前面确实出现过这种模式：
遇到一个实现障碍 → 解决它 → 得到一个局部结果 → 再围绕局部结果扩展。

每一步单看都合理，但它们加起来不一定自动回到原问题。“这是必要准备”不能成为无限延后的解释。
之前从 RL 滑到 SFT，属于改变了要研究的学习机制；这次围绕任务级代理做校准，性质不同，它确实在帮助解释 RL 经验价值。但如果接下来主要投入继续变成调先验、改善混合奖励预测、增加更多校准图，而来源组 RL 的迁移标签迟迟不产生，那它就会从主线的前置环节，变成事实上独立的主项目。
反过来，第一篇也不需要把所有七八种假说、所有模型、所有环境全部补齐，才能算回到主线。我们最初接受的本来就是：
在一个重要问题上做一个有限但扎实的推进。

现在一个合理的有限推进可以是：
经验可学习性的估计是否影响迁移价值预测？任务级与组合级的判断有何不同？这种关系是否随 learner 改变？

这比原先窄，但仍然在问“经验怎样产生可迁移能力”，不是只在问“如何让一个局部指标更好看”。
所以，我目前会给它这样的定位：
大问题没有换；候选假说的广度已经实质收窄；最新完成的是一个相关且有用的局部发现；下一步已设计的来源组迁移预测，仍然能够回到原问题的核心。
今天就用已有结果写论文，确实还不是最初想做的那篇。按 47 把信号与真实迁移收益接上，则可以成为原来那篇的一个更聚焦版本。
这两种状态不能混在一起。我也不该因为每轮都有新进展，就不断说“已经越来越接近论文”——接近与否，最终要看我们是否开始解释学习后的迁移收益，而不只是越来越准确地预测一组 reward 里有没有 0 和 1。
