所以，这已经是一个可以写进论文的实证结果，但不是足以包揽整类学习理论的否定性结论。
三、Coverage 的结果也要认真对待，不能只维护我们原先的故事
**历史 Coverage 的聚合 MSE 最低，比均值基线低约 64.71%；历史 Frontier 也低于均值基线。**它们本来就是预设对照，不能因为主候选输了，就把这些结果轻描淡写地放到角落。
但我进一步看了特征和重复，有两个限制很重要。
Coverage 在这批数据里其实只有两档
所有 16 个来源的历史 Coverage 只有 0.5 和 1.0 两种取值。四个留出来源中，MathAPI＋TradingBot 属于前一档，另外三组属于后一档，因此该预测器实际上只给出了两种预测：约 ＋3.96 和 ＋6.54 个百分点。
**这是一个粗粒度历史信号在这次划分中的预测结果，不是“结构多样性越高，经验越有价值”的证明。**Coverage 的名字，不能替代它实际测量了什么。
它也不是每个训练重复都赢
我用原封存预测和各重复的完整收益复算：**Coverage 对均值基线的优势在 r1、r2 上存在，在 r0 上不存在。**仓库的科学审阅也明确保留了这一点。
所以接下来不应该突然把项目改成：
“我们发现 Coverage 最好，开始设计 Coverage 采样算法。”

**预测对照表现较好，与按该信号选择经验、训练后确实更划算，是两项不同证据。**目前后者没有完成。
我的态度是：**把 Coverage 当成值得继续检验的竞争性解释，不把它捧成新的必胜主方法。**同样，不能因为它是廉价旧信号，就默认它不如我们精细设计的新信号。
四、RL 干预本身有收益，但尚未建立稳定的来源优先规则
完整 16 个来源的汇总是：
- 平均 \(G\)，相对共同起点：＋5.24 个百分点。
- Uniform 的平均 \(G\)：＋8.33 个百分点。
- 来源平均 \(V\)，相对对应 Uniform：－3.09 个百分点。
- 16 个来源的平均 \(G\) 都为正，其中 9 个在三个训练重复中均为正。
- 平均 \(V\) 为 13 负、2 零、1 正；没有来源在三个重复中都优于 Uniform。
这让我们能够把两个问题分开：
从这些来源训练，是否观察到迁移改善？
当前有平均正收益，也有一定的重复支持。

是否已经知道应该优先训练哪个来源？
还没有足够稳定的证据。

因此，不能因为预测主候选失败，就说这套 RL 实验没有学到东西；也不能因为来源平均 \(G\) 都为正，就说经验价值排序已经可靠。
还要提醒一个解释细节：报告提到单个训练终点两次评测的最大差为 25 个百分点，而四个留出来源平均 \(G\) 的跨度约为 3.65 个百分点。这确实提醒我们注意波动，但两者不是同一层级的统计量——一个是单分支最大差，一个是聚合均值跨度。**不能只凭这两个数，就断定所有来源差异都被噪声淹没。**下一步仍应使用已有逐任务、逐重复结果来解释，而不是自动要求追加一大批 seed。

六、接下来怎么走：我建议明确推进两项，而不是继续泛泛“按结果决定”
第一优先：落实既定的另一 learner 状态检验
继续使用事前指定的 Stage 0 Uniform r0 完整终点，不按本轮得分换祖先。这个状态已有七次优化器更新，保留完整权重、AdamW、历史与随机状态。仓库的阶段设计还记录：相对起点，16 组中有五组历史信号改变，历史未观察组从八组降为五组。因此，下一阶段确实可以检查当前信号关系是否随学习状态改变，而不是仅换个文件名重跑。
这一步必须清楚区分：
**冻结早期映射，直接预测晚阶段收益。**检验早期判断能否跨学习状态使用。
**在晚阶段重新拟合，再预测晚阶段留出来源。**检验同一信号在新状态内是否仍有信息，以及是否需要重新校准。
如果第二项有效、第一项无效，就不能笼统写“跨阶段有效”；更可能说明映射依赖 learner。两项都弱，也要保留这个结果，而不是马上换一个“更成熟”的祖先。
**原五个模型都要保留，不只追踪任务级 Beta，也不只追踪现在表现最好的 Coverage。**晚阶段的新信号形成后，先封存早→晚预测，再开放晚阶段目标标签。原计划已经规定了这个顺序，执行端只需补齐有限预算与实际运行登记，不再另开一轮准备研究。
同批辅助推进：把 58 的 H1 成功率候选落实，而不是一直只写在 scope 台账里
现在我赞成正式执行这项辅助比较。
理由不是“Beta 输了，找个新方法救场”，而是它回答一个此前没有区分清楚的问题：
容易成功的经验，与容易出现成功／失败差异的经验，是否具有不同的迁移预测关系？

58 已经给出了明确特征定义：对采样前 feature 面板中的任务成功比例等权平均。它与任务级混合概率不是同一个量，也可以复用既有早期数据及计划中的晚期探测，不必为此另开一批 GPU 采样。
执行边界同样明确：**原 Stage 0 五模型主表不变；新增成功率比较单独登记。**现在若分析 Stage 0 全部结果，应标为探索性；真正新增的验证，应在晚阶段目标标签出现前封存定义、拟合规则和预测。不能把已经看过的四个留出来源再称为一次全新的确认检验。
这一项只是补回 H1，不等于已经覆盖信息、恢复、兼容性和结构多样性。但它是一个具体、成本有限、能区分假说的推进，比再增加第三种 Beta 平滑方式更贴近最初的研究目标。
模型外推保留，写作现在开始收束
此前讨论的 Qwen3-8B 规模验证、非 Qwen 家族验证，以及模型代际的代表性问题，都不能因为当前主候选没有赢而被删掉。但也不应立刻对所有模型复制全部矩阵。
外部验证要检验的是这组已明确的关系和边界，而不是要求别的模型帮任务级 Beta 赢回来。当前先完成阶段轴，同时准备外部模型的有限执行方案。
论文的 Stage 0 结果段现在可以写了。比较准确的表述是：
在本研究的预设检验中，任务级建模对局部奖励机会的预测改进，并未转化为优于常数基线的迁移收益预测；廉价历史信号在有限留出条件下表现更好，但尚未建立稳定的来源选择规则。

这比“我们提出更好的经验价值分数”更符合现有证据，也比直接宣布“可学习性与迁移脱节”更扎实。
最终决定：继续主线，Stage 0 收口；下一批优先执行固定 learner 阶段检验，并将 H1 成功率作为独立登记的辅助对照一同验证。
