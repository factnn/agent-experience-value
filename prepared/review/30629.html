- `freeglut: ERROR: Internal error in function fgOpenWindow`

## Root Cause
Modern OpenGL libraries default to direct rendering for performance.
Direct rendering requires direct access to the graphics hardware,
which is not available over X forwarding.

## Solution
Set the LIBGL_ALWAYS_INDIRECT environment variable to force indirect rendering:
