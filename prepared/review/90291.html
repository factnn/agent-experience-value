# Liquidity CLI Private Key Error Solution

## Problem
When deploying a Liquidity contract, you get:

Failure: edsk3gUfUPyBSfrS9CCgmCiQsTCHGkviBDusMxDJstFtojtc1zcpsh is not a valid private key

The Liquidity CLI expects an **encrypted** private key (edesk... format), not an unencrypted one (edsk... format).

## Solutions

### Solution 1: Use tezos-client (Recommended)

1. Import your key into tezos-client:

tezos-client import secret key my_alias edsk3gUfUPyBSfrS9CCgmCiQsTCHGkviBDusMxDJstFtojtc1zcpsh

liquidity deploy-contract --client my_alias contract.lig

liquidity compile-contract contract.lig --no-deploy

tezos-client originate contract my_contract transferring 0 from my_alias \
