# SmartPy `michelson_v1.bad_stack` Error Fix

## The Problem

When using `sp.for` to iterate directly over `set.elements()`, SmartPy generates
Michelson code that has improper stack management:


# ❌ THIS CAUSES THE ERROR
sp.for item in self.data.link_names.elements():
    sp.trace("hello")


Error: `TezosOperationError: (permanent) proto.016-PtMumbai.michelson_v1.bad_stack`

## Why This Happens

The `set.elements()` method returns a list, but when used directly in a for loop,
SmartPy's compiler generates Michelson code that doesn't properly manage the stack.
The set operation and iteration happen in a way that confuses the Michelson type
checker.

## The Solution

Store the elements in a local variable BEFORE the for loop:


# ✅ CORRECT APPROACH
@sp.entrypoint
def process_links(self):
    # First, store elements in a local variable
    link_elements = sp.local("link_elements", self.data.link_names.elements())

    # Then iterate over that variable
    sp.for item in link_elements.value:
        sp.trace("Processing: ")
        sp.trace(item)


## Complete Working Example


import smartpy as sp

class MyContract(sp.Contract):
    def __init__(self):
        self.data.link_names = sp.set(t=sp.TString)

    @sp.entrypoint
    def add_link(self, name):
        self.data.link_names.add(name)

    @sp.entrypoint
    def process_links(self):
        # Store elements in local variable first
        link_elements = sp.local("link_elements", self.data.link_names.elements())

        # Now iterate safely
        sp.for item in link_elements.value:
            sp.trace("Processing link: ")
            sp.trace(item)


## Alternative Solution: Using list_map


@sp.entrypoint
def process_links(self):
    def process_item(item):
        sp.trace("Processing: ")
        sp.trace(item)

    sp.list_map(self.data.link_names.elements(), process_item)


## Key Takeaway

**Always store `set.elements()` (or similar operations) in a local variable**
before using it in a for loop. This ensures proper stack management in the
generated Michelson code.
