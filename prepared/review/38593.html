# Complete Solution: Permanent Keyboard Remapping (Caps Lock -> Ctrl)

## Problem
- Mapping doesn't load on startup or gets overwritten
- Mapping is forgotten when keyboard is plugged in

## Recommended Solution: Combine Xorg + Udev

### Part 1: Xorg Configuration (for startup)

Create /etc/X11/xorg.conf.d/00-keyboard.conf:

Section "InputClass"
    Identifier "system-keyboard"
    MatchIsKeyboard "on"
    Option "XkbOptions" "ctrl:nocaps"
EndSection


If directory doesn't exist:

sudo mkdir -p /etc/X11/xorg.conf.d


### Part 2: Handle Keyboard Hotplug (using udev + systemd)

Create /etc/udev/rules.d/99-keyboard-remap.rules:

ACTION=="add|change", SUBSYSTEM=="input", ENV{ID_INPUT_KEYBOARD}=="1", TAG+="systemd", ENV{SYSTEMD_USER_WANTS}+="keyboard-remap.service"


Create ~/.config/systemd/user/keyboard-remap.service:

[Unit]
Description=Remap Caps Lock to Ctrl
BindsTo=dev-input-%i.device

[Service]
Type=oneshot
ExecStart=/usr/bin/setxkbmap -option "ctrl:nocaps"
RemainAfterExit=yes

[Install]
WantedBy=default.target


Enable and start:

systemctl --user daemon-reload
systemctl --user enable keyboard-remap.service
sudo udevadm control --reload-rules


### Part 3: Alternative - Use localectl (system-wide)


sudo localectl set-x11-keymap us "" "ctrl:nocaps"


This writes to /etc/default/keyboard and should persist across reboots.
