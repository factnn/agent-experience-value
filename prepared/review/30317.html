# Solution: Converting MPEG-TS to Smooth Streaming without transcoding

## Problem 1: smoothstreaming muxer fails with "No bit rate set for stream 0"

**Cause:** The smoothstreaming muxer requires explicit bitrate information for each
stream. MPEG-TS files often don't include this metadata in the stream headers.

**Solution:** Manually specify the bitrates using `-b:v` and `-b:a` options.

Based on your input file's information:
- Total bitrate: 2500 kb/s
- Audio (MP2): 192 kb/s
- Video (H264): ~2308 kb/s (approximately total minus audio)

### Correct Command:

ffmpeg -i input.mpg -c copy -b:v 2500k -b:a 192k -f smoothstreaming ss_out


This will create a directory `ss_out` containing:
- `.ismv` - video/audio fragment files
- `.ism` - Smooth Streaming manifest file
- `.isma` - audio track file

---

## Problem 2: ISMV approach fails with "mfra size mismatch"

**Cause:** The MFRA (Movie Fragment Random Access) atom isn't properly written
or positioned in the ISMV file, causing ismindex to fail reading it.

**Solution A: Use ffmpeg with proper fragment flags**

ffmpeg -i input.mpg -c copy \
  -movflags isml+frag_keyframe+default_base_moof+omit_tfhd_offset \
  -write_empty_segments 1 \
  -f ismv output.ismv


Then run ismindex:

ismindex -n output output.ismv


**Note:** The `ismindex` tool is part of FFmpeg, not always installed by default.
You may need to build FFmpeg from source to get it, or use MP4Box as an alternative.

---

## Important Note About Audio Codec

Your input has **MP2 audio**, which may not be supported by all Smooth Streaming
players/servers. You might need to transcode just the audio to AAC:


ffmpeg -i input.mpg -c:v copy -c:a aac -b:a 128k -b:v 2500k -f smoothstreaming ss_out


Audio-only transcoding is much faster than video transcoding.

---

## Recommended Approach

The simplest and most reliable solution is **Problem 1's solution**:


ffmpeg -i input.mpg -c copy -b:v 2500k -b:a 192k -f smoothstreaming ss_out


This:
- Does NOT transcode (fast)
